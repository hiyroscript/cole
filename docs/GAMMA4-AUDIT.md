# Gamma 4.0 foundation audit

Audited base: `1a30900` (2026-10-26). This is a staged implementation of `max`, not completion of its whole roadmap. The 606-case published Gamma 3 fixture is regression data. Its checksum and historical artifacts remain unchanged. Baseline reproduction: 3,424 unit tests; 91/256 supported answers, 3/100 unsupported false accepts, 42/100 conversation completions, 8/100 compound completions, 50/50 no-effect adversarial cases.

| Area             | Confirmed behavior at the base                                                                                                       | Response in this milestone                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| Language         | `understand` discards everything before “but”; task grammar misses coordinated nouns and polite questions                            | Preserve contrast; typed, bounded task frames and protected data inputs                       |
| Retrieval        | Alias/title index drops candidates below 0.5; no answer-field discovery; framing dilutes matches                                     | Separate query rewriting and answer-field discovery, retaining original exact matches         |
| Acceptance       | Separated cosine neighbors can be marked accepted without evidence coverage                                                          | Independent evidence contract before semantic acceptance; exact identifier validation         |
| Context          | Last browser token wins even after “not”; browser statement returns before addressing the symptom; replanning replays obsolete facts | Affirmative browser roles; retain symptom; supersede old facts and avoid replay               |
| Composition      | Six-part budget exists, but subject lists and several dependent comparisons fail; source IDs can leak from the prior part            | Coordinated explanation tasks, two-to-four subject comparisons, per-task outcomes and sources |
| Tools            | Natural “What is 18% of 475?” does not invoke the existing calculator                                                                | User-only typed routing to existing bounded trusted tools; natural JSON analysis              |
| Coverage         | 700 core + 104 optional records; no broad general knowledge or complete applicability model                                          | Unchanged content; broader domain authoring remains work                                      |
| Documents        | 100 kB text files; line-based keyword search and opening extracts                                                                    | Unchanged; section indexing, grounded synthesis, PDF/DOCX remain work                         |
| Diagnostics      | Authored graphs and adaptive checks exist; arbitrary check explanations/resumption fail; old goal facts overwrite corrections        | Natural continuity and correction fixes; no causal certainty or physical measurements claimed |
| Runtime/security | Lazy optional inference, bounded parsing, permission-gated MV3, no retrieved-text tool dispatch                                      | Preserve boundaries; isolate compound network requests and structured data; test cancellation |

Hypotheses requiring further evidence: stronger learned language representations may improve paraphrase acceptance; section-aware document retrieval may improve citation usefulness; richer check metadata may improve diagnostic information gain. Neither implementation nor quality is established merely by listing these ideas. Current ranking utilities and token coverage are not probabilities or general semantic entailment.

Inspection covered the engine, parser, language/observation/context/case layers, retrieval/reranking/hybrid inference and worker, reasoning/workflow adapters, knowledge/packs, documents/calculator/capabilities/trusted tools, memory/public lookup, model and command contracts, app/storage/diagnostics, extension sender/permissions, existing tests/evaluators and CI. No destructive rewrite or stored-data migration is needed for this slice.
